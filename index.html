About

Why I made this

I’ve been exploring symmetry in a quantum circuit, and learning that symmetry can be used as an error detector for qubits piqued my interest.

A circuit designed to respect some symmetry has to give the same output for every symmetrically-transformed version of the problem, whether the problem has been rotated or reflected or any combination of the two. In other words, the circuit’s answer must not care about whether or not the problem has been rotated, because it must recognize that what it’s looking at is still the problem.

So, if an output is not ‘symmetric’ (i.e. it has changed after a symmetric transformation) then that change works as a free error detector; something in the hardware may have treated the qubits differently, and you can find that out without running any extra check.

The limit is that it only catches errors that treat qubits differently. An error that hits every qubit the same way makes the answer worse but still leaves it symmetric, so symmetry will not flag it.

I wanted to visualize how different errors could break symmetries, and to what extent. In this demo, the symmetry belongs to a kaleidoscope: every wedge of the kaleidoscope you draw is a qubit that is meant to behave exactly like the others, so every wedge should draw an identical copy of your line. When the output is not the same, one wedge stops matching another.

Different errors in the hardware break the symmetry in different ways, so I gave each one its own visible way of breaking the kaleidoscope, and you can compare IonQ and IBM side by side to see how the same kaleidoscope breaks differently depending on their different error rates.

What is happening

Each wedge of the kaleidoscope is one qubit in a ring. When your mouse moves, a small circuit runs on the ring, and a solid line is drawn in each wedge. On a perfect (no-error) machine, all qubits are treated equally and every action is performed exactly as intended. Since the circuit is symmetric, there is no difference between wedges. The chaos option demonstrates the opposite effect: symmetry is barely preserved from wedge to wedge.

A real machine is not perfect, and there are several different sources of error that can break a circuit’s symmetry. In this demo, each source breaks the symmetry in its own visible way, so you can tell them apart. Tick one off and it disappears, so you can see each error break the symmetry of the kaleidoscope by itself.

1Qubits are not identical

The error

In a symmetric circuit, turning or flipping the board just moves each square onto a different qubit, and the circuit is built so that this should not matter, because every qubit does the same job. That only works if the qubits are interchangeable.

In real hardware they are not quite: each qubit has its own one-qubit gate error, loses its state at its own rate while it waits, and is read out with its own measurement error. So the same board lands on better or worse qubits depending on its orientation, and the output changes.

Superconducting qubits are each made a little differently, and a chip's calibration lists a different error for each. Ions are identical atoms and IonQ publishes one number for all of them.

In the kaleidoscope

In a perfect kaleidoscope, every copy of your line is the same color. Here the copies come out in different colors: while the line you draw might be green, the other wedges' lines shift to pink, purple and so on. The bigger the differences between the qubits' errors, the further apart the colors.

The shifts are the same every time you draw, because they come from fixed differences between the qubits. IonQ's wedges all share one color, because IonQ publishes one number for all its qubits. IBM's do not.

2Two-qubit gates and connectivity

The error

The circuit applies the same two-qubit interaction between every pair of neighboring squares. These gates are the hardest operations, and they carry the largest error.

If some pairs are worse than others, or cannot interact directly and need extra swap gates, a turned board puts the same interaction on a different pair with a different error, and the output changes.

Any two ions can interact directly, so IonQ has the same error on every pair and needs no swaps. A superconducting chip only lets neighbors interact, so a distant pair needs swaps, and each swap adds error.

In the kaleidoscope

Every wedge should repeat the exact shape and direction of the line you draw. Here the copies are not repeated perfectly: each one curves away from your line in its own direction, and the bigger that pair's error, the more it bends. The copy under your cursor stays exact.

Which way each wedge bends is made up, the same for every machine, because no machine publishes it. Only the size of the bend comes from the error. IonQ bends every wedge by the same modest amount, and IBM bends a lot where swaps are needed.

3Shots

The error

A quantum computer cannot hand you a probability directly. Every run gives just one random outcome per qubit, a 0 or a 1, so to find out how likely an outcome is, it runs the same circuit again and again and counts. Each run is a shot. It is like trying to find out whether a coin is fair by flipping it: 10 flips could easily give 7 heads, while 10,000 flips will land very close to half.

That makes every answer an estimate, and an estimate from few shots is a little off by chance, even when the hardware does everything perfectly. That is the error.

For a symmetric circuit, the true probability of an outcome is the same for every orientation of the board, but you never see the true probability. You see an estimate from each orientation's own shots, and those estimates scatter: say 26% for one orientation, 33% for the next and 29% for another, when the truth is 30% for all of them. So the outputs differ between orientations and the symmetry looks broken, even though the circuit itself kept it.

The scatter shrinks with the square root of the number of shots. In this demo, in one second:

MachineShots in 1 secondTypical scatter
IonQ Forteabout 143about 4 percentage points
IBM Fezabout 379,000less than 0.1 percentage points

IonQ's number uses gate times I assumed, from IonQ Aria's published figures.

Shots are limited by time. A machine can only run so many in the time you give it, and a faster machine fits more. So IonQ's symmetry is blurred by chance much more than IBM's, with nothing wrong with its qubits. This is where machine speed shows up as broken symmetry.

It is also what sets shot errors apart from the other two: give a machine more time and shot errors shrink, but fixed differences between qubits do not average away.

In the kaleidoscope

When your line crosses itself or comes back to where it has been, it has made a closed shape, such as a loop, a circle or a petal, and the kaleidoscope detects that. Every wedge should repeat that shape in exactly the same way.

Instead, each wedge flips its own coin: it either fills its copy of the shape with a translucent color or leaves it empty, so the copies disagree with each other about whether the shape is filled.

Unlike the other two errors, which are fixed for each qubit, shot errors are random and different every time, so which wedges fill changes every time you draw a closed shape.

The fewer shots, the better the odds of a fill, so IonQ's copies disagree a lot and IBM's almost never do. Only the odds come from the shot count, which is set by how many runs fit in the 1 second each machine gets per dab. The coin flips are random.

Honesty notes

  • These are simulators, not real hardware. Real machines drift and differ from their published noise models.
  • Real differences are small. The exaggeration slider turns up how strongly each broken symmetry responds, the same for every machine. At ×1 the pictures are close to the true size.
  • IBM's frequency per qubit is only in the Sherbrooke snapshot, so broken symmetry 1 uses each qubit's one-qubit gate error, idle error and readout error for every chip.
  • Decoherence for ions uses T2 of about 1 second and gate times from IonQ Aria's published figures, with gates one after another. Both are my assumptions for the circuit time.
  • Max chaos is not a real machine. How an error becomes a color, a shape fill or a bend is an artistic choice, not physics.
  • The symmetric-circuit idea comes from geometric quantum machine learning (PennyLane's tic-tac-toe demo and Meyer et al., 2023). The perfect circuit is in main.py as plain Qiskit.
